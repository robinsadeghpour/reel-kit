# Sound effects

These four files were synthesised by `scripts/make_sfx.py` (a falling tone, a click, swept
noise). They are not samples of anything, so they carry no third-party licence: use them
under this repository's MIT licence, or treat them as public domain.

| File | Used for |
|---|---|
| `pop.wav` | a card appearing |
| `pop-small.wav` | small cards appearing in a row |
| `whoosh.wav` | a full-screen image coming in |
| `tick.wav` | a number sticker landing |

They are plain. To use better ones, put files with the same names (`.wav` or `.mp3`) in
your project's `sfx/` folder; those win over these. Check the licence of anything you
download: many "free" sound libraries allow use in your videos but not passing the files
on, which is why none are bundled here.

When you swap a sound, its timing and level may need adjusting. See "Sounds" in
`skills/edit/references/plan-format.md`.
