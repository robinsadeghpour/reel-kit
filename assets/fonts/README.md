# Font

`InterVariable.ttf` is [Inter](https://rsms.me/inter/) 4.1 by Rasmus Andersson and the
Inter Project Authors, under the SIL Open Font License 1.1 (`OFL.txt`).

All text in a video (stickers, labels, captions) is drawn with it. To use another
typeface, set `"font"` in your project's `reel.json` to a font file. A variable font with a
weight axis gives the full range of weights; a single-weight font is used as it is.
